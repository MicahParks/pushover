# Security policy

## Supported versions

Security fixes are released for the latest minor version of the current major version.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/MicahParks/pushover/security/advisories/new) instead of
opening a public issue. Include a description of the issue, the affected versions, and steps to reproduce it if
possible.

You should receive a response within a week. Once a fix is released, the advisory will be published with credit to the
reporter unless you ask otherwise.

Examples of issues in scope include leaking API tokens or encryption keys, flaws in the end-to-end encryption
implementation, and weaknesses in the callback handler.
